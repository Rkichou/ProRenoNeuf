# ProRenoNeuf

Site vitrine React + TypeScript + Vite, en français. Aucun déploiement effectué.

## Démarrer sous Windows

```powershell
npm.cmd install
npm.cmd run dev
```

Ouvrir l’adresse affichée par Vite. Production : `npm.cmd run build`, puis `npm.cmd run preview`.

## Fonctionnement

Navigation par ancres, menu mobile, liens d’appel et itinéraire. Le formulaire valide les informations et permet de télécharger un récapitulatif local. Il ne transmet aucune donnée et affiche explicitement cette limite. Aucun stockage persistant ni suivi.

## Avant publication

- Ajouter un service d’envoi, une adresse de réception vérifiée et les modalités de confidentialité associées.
- Compléter et faire valider les mentions légales : éditeur, directeur de publication, hébergeur et coordonnées réglementaires.
- Confirmer coordonnées, horaires et prestations avec l’entreprise.
- Remplacer si souhaité les photos d’illustration par des photos de chantiers autorisées. Les images actuelles sont chargées depuis Unsplash ; polices Google Fonts externes. Envisager l’hébergement local des ressources avant publication.
